# Imágenes de Asociación de Veteranos de la Fuerza Pública de Buenavista, Córdoba

Los archivos `01.svg` a `40.svg` y `hero.svg` son marcadores gráficos originales. **No son fotografías reales** y no deben presentarse como registro documental.

## Sustituir los marcadores
1. Consigue fotografías cuyo uso esté autorizado.
2. Optimízalas preferentemente a WebP y usa nombres consistentes, por ejemplo `01.webp` a `40.webp`.
3. Actualiza el campo `src` correspondiente en `assets/data/gallery.json`.
4. Cambia `alt`, `title`, `description`, `category` y `tags` para describir la imagen real.
5. Para la imagen de portada, sustituye `hero.svg` por una imagen aprobada y actualiza la ruta en `assets/css/layout.css` dentro de `.hero-backdrop`.
6. Prueba las rutas en GitHub Pages. Conserva las rutas relativas.

No uses imágenes de personas identificables sin autorización pertinente.
